The Expiry Tracker Mobile Application helps users:
Track expiration dates
Receive reminder notifications
Manage daily products easily
Reduce waste and improve safety




Problem Statement:
Difficult to remember expiry dates
Manual checking is inconvenient
Expired products create health risks
No centralized tracking system exists




Proposed Solution:
The application will:
Store product information
Monitor expiry dates automatically
Send reminder notifications
Display products close to expiration





Key Features:
User Authentication
Add/Edit/Delete Products
Expiry Notifications
Product Categories
Dashboard for Expiring Items
Cloud Data Storage




Methodology:

1. User logs into app

2. Adds product details

3. Data stored in Supabase

4. System tracks expiry dates

5. Notifications sent automatically
